# Bhanu Vamshi Portfolio

Responsive single-page portfolio built with plain HTML, CSS and JavaScript.

## Deploy to GitHub Pages

1. Create or open a GitHub repository.
2. Upload all files in this folder, keeping the `assets`, `css`, and `js` folders.
3. In **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`.
4. Save. GitHub Pages will publish `index.html`.

No build step or npm installation is required.

## Included
- Dark mode by default
- Light mode toggle with localStorage persistence
- Responsive desktop/tablet/mobile layout
- Smooth scrolling and active navigation
- Project case-study modal
- Resume download
- Contact form using the visitor's email client
- Resume PDF included under `assets/`
